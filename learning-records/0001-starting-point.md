# Starting point: total beginner, with a repo already published for him

Daniel is new to both git and GitHub — no assumed vocabulary, no prior command-line git.
His mission is publishing his own projects, and lessons are sized to 10–15 minutes.

The non-obvious part: the `Admin and Setup` repo was **already initialised, committed, and
pushed to `dancohen88/Admin-and-Setup` by a prior agent session**, not by him. So the
workspace looks more advanced than his skills are. Do not read the existence of a synced
public repo as evidence he can push — as of this record he has never run `git add`,
`git commit`, or `git push` himself, and `gh` had never been authenticated.

**Implications:** teach the `add → commit → push` loop as genuinely new material despite the
repo appearing "done." Verify each mechanical step actually ran rather than assuming it.
